# 🌍 World Time App

![World Time App Demo](assets/Gif/demo.gif)

## 🇧🇷 Português

Aplicação web simples que exibe o horário atual em diferentes fusos horários ao redor do mundo.

Este projeto foi desenvolvido para praticar **manipulação de datas em JavaScript**, **lógica de fusos horários** e **desenvolvimento de interfaces front-end**.

### 📌 Funcionalidades

* ⏰ Exibição do horário atual
* 🌎 Suporte a diferentes fusos horários
* 🔄 Atualização automática do relógio
* 🎨 Interface simples e limpa
* 📱 Layout responsivo

### 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript

### ⚙️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/Neto13k/world-time-app.git
```

Entre na pasta:

```bash
cd world-time-app
```

Abra o arquivo **index.html** no navegador.

* 🔄 Real-time clock updates
* 🎨 Clean and simple interface
* 📱 Responsive layout

### 🛠️ Technologies

* HTML
* CSS
* JavaScript
